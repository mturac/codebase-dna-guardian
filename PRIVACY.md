# Privacy Policy

**Codebase DNA Guardian** — Last updated: May 2026

## Summary

This plugin does not collect, transmit, or store any personal data or telemetry.

## What this plugin does

Codebase DNA Guardian runs entirely locally inside Claude Code. It:

- Reads files in your local project directory
- Writes `.claude/dna.md` and `.claude/dna-history.md` to your local project
- Generates a local HTML report served on localhost (for `/dna-preview`)

## What this plugin does NOT do

- Does not send any data to external servers
- Does not collect analytics or telemetry
- Does not read or transmit file contents outside your local machine
- Does not require authentication or account creation
- Does not store any data beyond your local `.claude/` directory

## Third-party services

This plugin has no backend and does not integrate with any third-party services.
